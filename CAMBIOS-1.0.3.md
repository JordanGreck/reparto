# Reparto 1.0.3

Se agregan calles numeradas de Paraná que no estaban identificadas en Reparto, incluyendo **Calle 893 y Calle 868**, con datos oficiales de Georef / INDEC.

- Los nombres y trazados complementarios aparecen al acercar el mapa.
- Se puede buscar `Calle 893`, `Calle 868`, `893 y 868`, `893 y Balbín` o `868 y Parera`.
- Una calle sin altura verificada pide ubicar y confirmar el domicilio antes de mostrar una tarifa.
- Se conservan las zonas guardadas, colores, precios, prioridades, respaldos y búsquedas anteriores.
- Se agregan 125 registros de vías (122 nombres numerados) y 281 nodos de intersección; el catálogo original permanece intacto.

## Actualizar

Cerrá Reparto y ejecutá **Reparto-Instalador-1.0.3.exe** con el mismo usuario de Windows. No hace falta volver a dibujar las zonas ni importar un respaldo al actualizar en la misma PC.

Los datos complementarios se distribuyen con atribución a Servicio Georef / INDEC bajo CC BY 4.0. La cobertura depende de los registros oficiales disponibles. No se inventan alturas que no puedan verificarse.
