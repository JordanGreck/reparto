# Reparto 1.0.1

Los colores de las zonas ya no se mezclan cuando se superponen. En cada cruce se ve el color de la zona activa con mayor prioridad, conservando la transparencia necesaria para leer las calles.

- Seleccionar una zona no tapa el color de otra con mayor prioridad.
- Los contornos originales, nombres, precios y prioridades se conservan.
- Al editar se muestra el relleno completo de la zona que se está ajustando; al guardar o cancelar se recupera la vista por prioridades.
- La exportación del mapa también conserva los colores sin mezcla.

## Actualizar

Cerrá Reparto y ejecutá `Reparto-Instalador-1.0.1.exe` para actualizar la instalación existente. Usá el mismo usuario de Windows. La actualización mantiene la identidad de la aplicación y el formato de sus datos; no requiere volver a dibujar las zonas.

Esta entrega incluye el instalador y el código fuente. No modifica por sí sola la aplicación que ya está instalada.
