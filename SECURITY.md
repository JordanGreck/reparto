# Informar un problema de seguridad

Si encontrás una posible vulnerabilidad en Reparto, usá el canal privado de
GitHub: [informar una vulnerabilidad](https://github.com/JordanGreck/reparto/security/advisories/new).

También podés escribir a [jordangreck@gmail.com](mailto:jordangreck@gmail.com).
Evitá publicar detalles de explotación en los issues públicos mientras se
investiga el problema.

Incluí la versión de Reparto y de Windows, los pasos para reproducir el problema
y su impacto esperado. Usá ejemplos ficticios: no adjuntes contraseñas, claves,
direcciones de clientes ni archivos personales. Realizá pruebas únicamente
sobre equipos y datos propios o con autorización de sus responsables.

Las correcciones se prepararán para la versión más reciente de Reparto. Las
propuestas de actualización de dependencias deben revisarse y pasar las
comprobaciones automáticas antes de incorporarse; no se aceptan automáticamente.
